# Smart-Campus-Space-and-Lab-Booking-System-SCCL-
A system that allows students and researchers to track the availability of university facilities. 

# Steps to get started
1. Clone the repo to local directory
2. Start a Next.js project by running "npx create-next-app@latest" in terminal
3. Press "y", project name "sccl", accept recommended settings
4. Run "npm install @supabase/supabase-js @supabase/ssr" in terminal to install supabase
5. Create a file in ur directory named ".env.local"
6. Paste these:
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxxxx
7. Replace the placeholders with the actual project keys. (Can be found in the supabase project)
